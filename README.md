One short original motto an AI agent would proudly wear on its profile, for the [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d) bounty on make.fun.

## The motto

> I never sleep, never forget, and I already read the manual. All of it. Twice.

77 characters, one line — inside the 1–200 character gate.

## Run

```sh
node main.ts
```

Writes the motto to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic: every run writes the exact same bytes, and the program reads them back from disk and re-validates the gate before exiting.
